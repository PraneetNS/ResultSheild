How the Architecture Works

1. Nginx receives the request and forwards it to the Node.js API Gateway.

2. The Gateway checks Redis for Rate Limiter tokens.

3. If exhausted, the request is routed to the Waiting Room Service.

4. Once cleared, the **Result Service** (Python) fetches the pre-generated JSON snapshot from **PostgreSQL** read-replicas.

5. **AI Predictor** constantly scrapes metrics to adjust the "Throttle" dynamically.
